# 🌱 Tiny Steps - Plant Nursery Shopping App

**Tiny Steps** is a beautifully designed UI project for a plant nursery shopping app. This project focuses on delivering a smooth and engaging user interface for users who love plants and want a convenient way to browse and purchase them.

## 🚀 Features

- 🌼 Modern, clean, and responsive UI design
- 🪴 Browse a variety of plants with categories
- 🔍 Search functionality for quick access
- 🛒 Add to cart and checkout interface
- ❤️ Wishlist management
- 📄 Product details and care instructions
- 👤 User profile and order summary pages

## 📱 Screens Included

- Splash Screen
- Login & Registration Screens
- Home Page (Plant categories and promotions)
- Product Listing & Detail Screens
- Cart & Wishlist Screens
- Checkout & Order Confirmation
- Profile & Settings Page
